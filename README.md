Inventory Manager App (React Native + Expo)

A clean and modern Inventory Management Mobile Application built with React Native + Expo, designed for pharmacies, shops, poultry farms, warehouses, and small businesses needing fast, simple stock control.

This app supports:
✔ Real-time stock tracking
✔ Stock adjustments
✔ Full edit history
✔ Price management (₦ Nigerian format)
✔ Categories, minimum stock levels, and alerts
✔ Local storage (no internet required)

Features
📊 Dashboard
Total items, low stock alerts, total inventory value
Recent activity log
Quick actions (Add item, View inventory)

Inventory List
Sortable item list
Clean card layout
Tap any item to view details
Add item button with modal popup

📘 Item Detail Page
Category, quantity, price, value, and location
Clear stock-level indicators
Edit item modal
Adjust stock modal
Full history log (Add / Remove / Edited)

🔄 Stock Adjustment Modal
Add or remove stock
Requires quantity + reason
Automatically records history

✏ Edit Item Modal
Edit anything except quantity
Editing does not appear in stock history
Protects stock accuracy

💾 Offline Storage
Everything is saved locally using AsyncStorage
Your data stays on your device
No internet required
